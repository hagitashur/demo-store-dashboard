# דפדף ושחק: דשבורד מכירות

דשבורד מכירות לחנות אונליין בדויה שמוכרת ספרים, משחקים וציוד לבית ספר.
תרגיל בקורס מטמיעי AI: אפיון, יצירת נתונים, בניית דשבורד וחיבור למקור נתונים.

**כל הנתונים בפרויקט בדויים.** הם נוצרו בסקריפט, ואין בהם מידע אמיתי של אדם או של עסק.

קישור חי: https://hagitashur.github.io/demo-store-dashboard/

## מה יש בדשבורד
- הכנסות, החזרים והכנסה לאחר החזרים, עם השוואה לתקופה הקודמת. ליד ההחזרים מופיע גם האחוז.
- מספר הזמנות וערך הזמנה ממוצע.
- גרף הכנסה לאורך זמן, מוצרים מובילים וסטטוס פריטים.
- סינון לפי תקופה (7, 30, 90 ימים) ולפי קטגוריה, ולחיצה על מוצר או סטטוס מסננת את כל הדף.
- טבלת הזמנות עם חיפוש ומיון.
- מצב בהיר וכהה, עברית מימין לשמאל, מותאם לטלפון.
- תצוגת טבלה לכל גרף, והסבר ליד כל מדד.

## איך מריצים במחשב
הדף קורא את `data.json`, והדפדפן לא מאפשר את זה בפתיחה ישירה של הקובץ. מריצים שרת מקומי בתיקייה:

```bash
python -m http.server 8765
```

ופותחים בדפדפן את `http://127.0.0.1:8765/index.html`.

## מבנה הפרויקט
```
index.html                      הדשבורד (דף אחד)
data.json                       הנתונים שהדף קורא
vendor/chart.umd.min.js         ספריית Chart.js 4.5.1 (רישיון MIT, ראו chartjs-LICENSE.md)
data/products.csv, sales.csv    נתוני הדמה בפורמט CSV
data/expected_metrics.json      מדדים שחושבו בפייתון, לבדיקת הדף
scripts/generate_fake_data.py   יצירת נתוני הדמה (זרע קבוע, אותה תוצאה בכל הרצה)
scripts/check_metrics.py        חישוב המדדים בפייתון
scripts/build_data_json.py      יצירת data.json מקובצי ה-CSV
```

## איך הנתונים נוצרים
```bash
python scripts/generate_fake_data.py   # יוצר את קובצי ה-CSV
python scripts/check_metrics.py        # מחשב מדדים לבדיקה
python scripts/build_data_json.py      # יוצר את data.json ומשווה אותו לחישוב
```
הדף מחשב את המדדים בדפדפן. הוא נבדק מול `expected_metrics.json`, והתוצאות זהות.

## הגדרות המדדים
| מדד | חישוב |
|---|---|
| הכנסות | סכום כל שורות המכירה בתקופה (כמות כפול מחיר), כולל מה שהוחזר |
| החזרים | סכום השורות בסטטוס "הוחזר", בתאריך המכירה המקורית |
| הכנסה לאחר החזרים | הכנסות פחות החזרים |
| אחוז החזרים | החזרים חלקי הכנסות |
| ערך הזמנה ממוצע | הכנסה לאחר החזרים חלקי מספר ההזמנות |

התקופות נמדדות מהתאריך האחרון בנתונים. ההשוואה היא מול תקופה קודמת באותו אורך.

## חיבור לנתונים
בשלב הנוכחי הנתונים נוצרים מקובצי CSV. השלב הבא הוא מקור נתונים ב-Airtable, עם סקריפט שמושך ממנו ויוצר את אותו `data.json`. האסימון של Airtable יישמר בקובץ `.env` מקומי, שלא עולה לריפו.

## אבטחה
- אין בריפו מפתחות, אסימונים או סיסמאות, והקובץ `.env` חסום ב-`.gitignore`.
- הלקוחות בנתונים מופיעות רק כקוד אנונימי, למשל `לקוחה-001`.
- שמות המוצרים בדויים.
